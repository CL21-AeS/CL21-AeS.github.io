# Le app di CumLaude21

Ogni cartella è un'app: un file HTML solo, senza dipendenze, che gira nel browser del telefono.
I dati di chi la usa restano nel suo browser — qui dentro non c'è nessun dato di nessuno.

- `lista/` — Dalla Lista al Sì: dalla lista nomi alla chiusura
- `clienti/` — Clienti e Riordini: chi compra, cosa usa, quando sta finendo

## Aggiornare un'app

I file di questa cartella sono **copie pronte da pubblicare**. Le versioni di lavoro stanno nel Dropbox
del progetto (`Step_By_Step/dalla-lista-al-si.html` e `Mini_App/clienti-e-riordini.html`): si modifica
là, si ricopia qui come `index.html`, e si ricarica sopra al vecchio file.

Ricaricare il file non tocca i dati di nessuno: stanno nei browser, non nelle pagine.
